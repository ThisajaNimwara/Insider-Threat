### **Project Description / Summary**
Developed **Insider Threat Detector**, an advanced multi-agent AI security pipeline for identifying insider threats and anomalous user behaviors within enterprise SIEM log events. Built a hybrid detection engine by combining custom machine learning models (an ensemble of CatBoost and Gradient Boosting classifiers) with generative LLM agents (Mistral for localized contextual reasoning and Gemini for global audits and false-positive mitigation). The pipeline dynamically enriches raw logs with HR context and historical telemetry, calculates unified threat indices using a weighted ensemble scoring engine, and outputs detailed risk classifications. Additionally, built an interactive multi-page Streamlit dashboard to facilitate real-time alert analysis, telemetry breakdowns, and automated executive report generation.
